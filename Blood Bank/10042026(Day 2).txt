VPC and components:

Subnets: A subnets in Amazon Virtual Private cloud(VPC) is a segment of the IP address range within a VPC
1.Public subnet
2.Private subnet


CIDR blocks: -A CIDR block defines the IP address range for a subnet within a VPC.
-For example, you can allocate a subnet with a CIDR block like 10.0.1.0/24, which allows for up to 256 IP addresses(254 usable).      //2^8 i.e 2^32-24
-Each subnet must have a unique CIDR block within the VPC's range.

Internet Gateway: -An internet gateway(IGW) in a VPC is a component in AWS that allows communication between instances in your VPC and the internet.
-It acts as a bridge for network traffic, enabling resources in your VPC to send and receive data from the internet.

NAT Gateways: NAT gateways (AWS Managed) & NAT instances(self managed)allow your instances in your private subnets to access the internet while remaining private.

NACL and Security group: NACL (network access control list)

Monitoring services in AWS
AWS provides several monitoring services that help you track the health, performance, and security of your infrastructure.

**AWS CloudWatch: -**It is a powerful and comprehensive monitoring service that provides real time insights into your AWS resources, application, and services
-It helps you to tack performance, monitor system health, and automated actions based on matrices and logs.
-cloud watch plays a central role in managing operational visibility, performance monitoring, and security within your AWS infrastructure.


key components:
CloudWatch matric
CloudWatch alarms

CloudWatch dashboard

CloudWatch matric:
**-**CloudWatch metrics provide data points for your AWS resources and applications.
-Metrics are data about various parameters like CPU, utilization, network traffic, and disk I/O.

Metrics management:
Visualization
Aggregation
Collection

Types of metrics:
1.Custom metrics-User-defined metrics created by pushing application specific data into CloudWatch.
2.Standard metrics-Default metrices provides by AWS  services like EC2, RDS, and S3.
3.Detailed metrics-More granular metrics available for certain services, offering data every 1 minute.




CloudWatch Alarms :
Amazon CloudWatch Alarms help you monitor specific metrics or conditions within your AWS environment.
You can use CloudWatch Alarms to take automated actions, such as sending notifications or performing corrective actions(e.g. scaling EC2 instance)when your resources or applications exceed or fall below predefined thresholds.

Threshholds and states:
state of alarms:1.OK
2.ALARM
3.INSUFFICIENT_DATA

Alarms action:
1.Sending notifications
